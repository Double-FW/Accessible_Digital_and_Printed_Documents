# Terminology alignment

Use [Double-FW Terminology and Principles](https://github.com/Double-FW/Terminology-and-Principles). The inspected revision is `219b5feddd271bcdf70ea0ac0c4bc5c62fe9a0f4`; its [governance](https://github.com/Double-FW/Terminology-and-Principles/blob/219b5feddd271bcdf70ea0ac0c4bc5c62fe9a0f4/GOVERNANCE.md) and [decision register](https://github.com/Double-FW/Terminology-and-Principles/blob/219b5feddd271bcdf70ea0ac0c4bc5c62fe9a0f4/review/DECISIONS.md) distinguish scoped approved resolutions from proposed glossary wording. This alignment does not approve all definitions or adopt an organisation’s policy.

## Experience and meaning

| Distinction | Document application |
| --- | --- |
| Accessibility and inclusion | Address barriers to reading, participation and action. File availability alone does not establish either. |
| Task completion | Verify the intended outcome and understanding; opening a file or reaching its last page is insufficient. |
| Content consumption and engagement | Investigate access to meaning and chosen participation. Longer reading time may indicate difficulty. |
| User choice and preferences | Verify relevant font, size, theme, reading mode and edition choices in actual software or physical output; do not promise unsupported options. |
| Equivalent/comparable experience (D02) | Compare outcomes, effort, privacy, availability, control and dignity across editions. Identical pagination is not required. |
| Satisfactory and satisfaction (D01) | Satisfactory is the proposed Double-FW experience principle; satisfaction is a person’s assessment. A positive rating cannot cancel an unmet requirement. |
| Emotional lenses (D03) | Feeling Seen, Feeling Capable, Feeling Confident, Feeling Safe and Feeling Valued are intended qualities and research lenses. An agent cannot assign those feelings from a technical pass. |

The guide’s emotional, functional and technical lenses separate audience experience, task performance and delivery conditions; they are not externally standardised conformance classes. Respect identity and language preferences, including Deaf and neurodivergent identities. Do not infer diagnosis, literacy, preference or ability from a selected format.

## Standards and identifiers

Use adopted Double-FW meanings for its own methods; preserve external source meanings when citing standards, law, technical specifications and contracts (D08). A local typography default is not automatically WCAG. WCAG robustness, Agentic Robustness and reliability of a document/export pipeline have different scopes (D06). Feeling Safe is not proof of security or assistive-technology interoperability.

Name the owning source with cognitive identifiers `CP-01`–`CP-10` (D04). Use ACT-style procedural test for a local structured procedure and user-oriented task script for a complete activity. W3C ACT refers to the actual W3C work and rule status, not any generated checklist (D05). PLAN/TYPE/QA and other local IDs belong to this guide; S001-style retrieval IDs are navigation. Neither is an external criterion or approval.

## Evidence and decisions

Keep observations, participant accounts, estimates, hypotheses, synthetic examples, proposals and approvals distinct (D07).

| Result | Meaning |
| --- | --- |
| `pass` | Evidence supports the specified check for the exact output, environment and scope. Not universal access or full conformance. |
| `fail` | Evidence shows the scoped requirement was not met. |
| `unknown` | Available evidence has not established the result. |
| `not_tested` | The specified evaluation did not run. |
| `not_applicable` | The property does not apply to the stated scope; record the rationale and relevant decision. |

Unresolved describes an open issue or decision, separately from its evaluation result. Draft readiness, human acceptance, release authority, distribution and actual reader outcomes are separate events. A repository merge, export, completed template or checker result does not establish approval. Keep retrieval, editorial update, test execution and approval dates separate; an updated file does not renew old evidence.
