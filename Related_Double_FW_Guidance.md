# Related public Double-FW guidance

These repositories were confirmed public on 21 November 2026. They provide optional specialist detail; no private repository is required to use this guide. Public availability can change. If a route becomes unavailable, explain the missing evidence, continue independent work using the maintained local guide and do not invent its contents or substitute a different revision silently.

| Resource | Relevant use |
| --- | --- |
| [Terminology and Principles](https://github.com/Double-FW/Terminology-and-Principles) | Shared meanings, governance and evidence distinctions; check the status of each definition. |
| [Accessible typography](https://github.com/Double-FW/Accessible-Typography-for-UX-and-Brand-Systems) | Contextual letterforms, hierarchy, reading performance and brand; not a universal font whitelist. |
| [Accessible charts, graphs and maps](https://github.com/Double-FW/Accessible_Charts_Graphs_and_Maps) | Purpose, data relationships, uncertainty and nonvisual access to findings. |
| [Cognitive UX design](https://github.com/Double-FW/Cognitive-UX-Design) | Comprehension, task structure, effort and user choice; retain owning CP identifiers. |
| [QA accessibility testing](https://github.com/Double-FW/QA_Accessibility_Testing) | Scoped evaluation, evidence and task checks; no generated record is proof of execution. |
| [Data ethics and disability](https://github.com/Double-FW/Data_Ethics_and_Disability) | Research and data handling; do not expose participant information in public datasets. |
| [POUR for branding systems and CX](https://github.com/Double-FW/POUR-for-Branding-Systems-and-CX) | Functional and emotional experience lenses, POURS and Satisfactory; not a fifth official WCAG principle. |
| [Accessible email design](https://github.com/Double-FW/Accessible-Email-Design) | Delivery messages, meaningful actions and linked/attached edition journeys. |
| [Accessible film, TV and video production](https://github.com/Double-FW/Accessible-Film-TV-and-Video-Content-Production-Management) | Coordinate multimedia embedded in or supporting publications. |
| [Audio descriptions](https://github.com/Double-FW/Audio-Descriptions) | Commission and review access to meaningful visuals in audiovisual material. |
| [Closed captions and subtitles](https://github.com/Double-FW/Closed-Caption-Subtitles) | Synchronised access to meaningful audio, separate from document captions. |

Use the main guide’s primary technical references when assessing an external standard; these repositories do not replace the standard or establish legal applicability. Record the exact revision and sections actually used. A public link does not mean the entire linked work is copied into this repository or licensed under its MIT licence. See [NOTICE](NOTICE.md).
