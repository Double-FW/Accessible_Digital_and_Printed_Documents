The prompt pack adds four navigation/application files: its README, RAG reference, this coverage register and the activity guide. They are not extra independent authorities for the same requirements. The activity guide retains eight activities and sixteen illustrative prompts.

External works and the eleven historical attachments listed in section 12 of S001 are not bundled or claimed as verified. Linked specialist repositories are optional public sources, not copied corpus content. The earlier duplicated Sources directory and embedded source bodies have been removed from the maintained tree to prevent drift; old versions remain in Git history.

After a source change, check index paths, source meanings, stable rule IDs, qualifiers and affected prompts together. An inventory check does not establish that any publication, retrieval model or dataset meets accessibility or training-quality requirements.
